# Web Quality Rules

## UX
- Check hierarchy, spacing, contrast, readability, and CTA clarity.
- Avoid duplicated sections or repeated copy.
- Keep navigation understandable.
- Ensure interactive elements have clear states.

## Responsive
- Design for small screens first.
- Check mobile and desktop widths.
- Prevent horizontal overflow.
- Ensure images, cards, tables, and navigation adapt correctly.

## Accessibility
- Use semantic HTML.
- Provide meaningful alt text for informative images.
- Maintain visible focus states.
- Associate labels with form controls.
- Do not rely on color alone to communicate meaning.
- Maintain reasonable heading hierarchy.

## Performance
- Optimize large images and avoid unnecessary assets.
- Lazy-load non-critical media when appropriate.
- Avoid unnecessary client-side work.
- Do not add large dependencies for trivial functionality.

## SEO
- Use meaningful page titles and descriptions.
- Use semantic headings.
- Ensure important pages are internally linked.
- Preserve canonical/indexing configuration when present.
- Use structured data only when accurate and appropriate.

## Content integrity
Never invent testimonials, ratings, awards, statistics, business claims, opening hours, prices, addresses, or social accounts. Clearly distinguish verified client-provided information from placeholders.
